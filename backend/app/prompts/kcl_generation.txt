// Variables (const only — no let/var)
const baseLength = 200   // mm
const baseWidth  = 150
const baseThick  = 15

// Sketch + extrude (PRIMARY way to create solids)
const basePlate = startSketchOn('XY')
  |> startProfileAt([0, 0], %)
  |> line([baseLength, 0], %)
  |> line([0, baseWidth], %)
  |> line([-baseLength, 0], %)
  |> close(%)
  |> extrude(baseThick, %)

// Cylinder — position at creation, height goes in +Z from origin.z
const pin1 = cylinder({
  origin: { x: 50, y: 75, z: baseThick },
  radius: 3,
  height: 12
})

// Boolean subtract (remove material FROM a solid)
const plateWithHole = basePlate |> subtract(pin1, %)

// Fillet edges — tags must be edge tags created during the sketch
// Only use tags you explicitly set with tag: during sketch
const taggedSketch = startSketchOn('XY')
  |> startProfileAt([0, 0], %)
  |> line([100, 0], %, $edge1)
  |> line([0, 50], %)
  |> line([-100, 0], %)
  |> close(%)
  |> extrude(10, %)
const withFillet = fillet({ radius: 1, tags: [edge1] }, taggedSketch)

// Linear pattern (repeats a solid N times along an axis)
// distance = spacing between each repetition (not total span)
const bushingHole = cylinder({ origin: { x: 50, y: 50, z: baseThick }, radius: 5, height: 15 })
const row = patternLinear3d({
  axis: [1, 0, 0],
  repetitions: 7,
  distance: 75    // 75mm between each copy
}, bushingHole)

// 2D pattern (use nested patternLinear3d)
const rowCopy = patternLinear3d({
  axis: [0, 1, 0],
  repetitions: 5,
  distance: 60
}, row)

// Boolean subtract a pattern from a plate
const drilledPlate = basePlate |> subtract(rowCopy, %)

## CRITICAL RULES — violating these causes Zoo.dev compilation failure:
1. NO `add()` function — there is no boolean union. Build compound shapes by combining sketches instead, or describe multiple separate bodies as separate `const` variables. The final model variable should be your base plate with all features subtracted.
2. NO `move()` function — position all objects at their final coordinates in `origin:` at creation time.
3. NO `union()` function — same as rule 1.
4. NO `floor()`, `ceil()`, `round()` — compute discrete numbers explicitly in the prompt.
5. NO dynamic tag strings like backtick strings or f-strings — fillet tags must be variable references like `$myEdge` set inline.
6. patternLinear3d `distance` = gap between copies, NOT total span. For N copies spanning X mm: distance = X / (N-1).
7. `cylinder()` origin.z is where the cylinder BASE starts. To place on top of baseThick plate: origin.z = baseThick.
8. ALL variables must be `const`. KCL has no mutable variables.
9. Keep the model SIMPLE — a flat base plate with cylindrical features subtracted. DO NOT attempt complex multi-solid assembly with many boolean chains as these fail to compile.
10. Return ONLY valid KCL code — no markdown fences, no explanatory text outside `//` comments.

## Fixture Design Standards:

### 3-2-1 Locating Principle
- Datum A (primary, 3 support pads): Three cylinder bosses on base plate for Z support
- Datum B (secondary, 2 pins): Two locating pins along longest edge
- Datum C (tertiary, 1 pin): Single stop pin on perpendicular edge

### Dimensional Rules
- Base plate: Part envelope + 25mm margins all sides, 15mm thick minimum

- Pin holes: ⌀6 + 0.20mm FDM tolerance compensation
- Clamp slots: 12mm wide × 60mm long
- Mount holes: 8mm dia on 28mm grid (Siegmund)
