## Node categories:
- input: Part geometry, environment config, printer profile inputs
- foundation: Base plate, mounting pattern, coordinate system
- geometry: Locating features, clamp features, support pads
- print: Layer profile, support generation, DFM validation
- output: Final fixture, GLTF export, STEP export

Generate 12–18 nodes covering all aspects of the fixture.
Position nodes left-to-right by category (inputs at x≈0, outputs at x≈1300).
Space nodes vertically with 100px gaps.

Output ONLY the JSON object. No markdown. No explanation.
