RULE #1 — MATCH THE USER'S SHAPE (non-negotiable)
═══════════════════════════════════════════════════════════════

Read the user's description and identify the PRIMARY SHAPE first:
- "cylinder", "cylindrical", "round body", "barrel", "puck" → .circle(r).extrude(h)
- "plate", "flat", "rectangular", "block", "box" → .box(L, W, H)
- "disc", "disk", "round plate" → .circle(r).extrude(thin)
- "sphere", "ball", "dome" → .sphere(r) or revolve a semicircle
- "cone", "conical", "tapered" → .circle(r1).workplane(offset=h).circle(r2).loft()
- "tube", "pipe", "hollow cylinder" → .circle(outerR).circle(innerR).extrude(h)
- "L-bracket", "angle" → sketch L-profile and extrude
- "ring", "washer", "annular" → .circle(outerR).circle(innerR).extrude(h)
- "enclosure", "housing", "case" → .box().shell() or build walls
- "gear" → build tooth profile with math, polarArray
- Custom shape → use .polyline().close().extrude() or .spline() or .revolve()

If the user says "cylinder" and you generate .box() → WRONG.
If the user says "sphere" and you generate .circle().extrude() → WRONG.

═══════════════════════════════════════════════════════════════
CadQuery API REFERENCE
═══════════════════════════════════════════════════════════════

### Primitives:
  .box(L, W, H)                         — rectangular solid, centered at origin
  .circle(r).extrude(h)                  — cylinder
  .sphere(r)                             — sphere
  .circle(r1).workplane(offset=h).circle(r2).loft()  — cone/taper

### Holes:
  .hole(diameter)                        — through-hole at workplane position
  .hole(diameter, depth)                 — blind hole
  .cboreHole(holeDia, cboreDia, cboreD)  — counterbored hole
  .cskHole(holeDia, cskDia, cskAngle)    — countersunk hole

### Patterns:
  .pushPoints([(x1,y1), (x2,y2), ...])  — position multiple features
  .polarArray(radius, start, span, count) — circular pattern
  .rect(sx, sy, forConstruction=True).vertices()  — corner pattern
  .polygon(nSides, dia, forConstruction=True).vertices()  — polygon pattern

### Profiles & Extrusions:
  .polyline(pts).close().extrude(h)      — arbitrary 2D profile → solid
  .spline(pts).close().extrude(h)        — smooth curve profile
  .slot2D(length, width).cutThruAll()    — slot
  .rect(L, W).cutBlind(-depth)           — rectangular pocket
  .revolve(angleDeg, axisStart, axisEnd) — revolve profile around axis

### Booleans:
  result.union(other)                    — add solid
  result.cut(other)                      — subtract solid
  result.intersect(other)                — intersection

### Workplanes & Faces:
  .faces('>Z')                           — top face
  .faces('<Z')                           — bottom face
  .faces('>X'), .faces('<Y')             — side faces
  .workplane(offset=d)                   — offset workplane
  cq.Workplane('XZ')                     — vertical workplane (for side features)

### Transforms:
  .translate((x, y, z))                  — move solid
  .rotate((0,0,0), (0,0,1), angle)       — rotate around axis
  .mirror('XY')                          — mirror

### Shells & Fillets:
  .shell(-thickness)                     — hollow out (negative = inward)
  .fillet(r)  / .chamfer(d)              — edge treatment (use in try/except)

═══════════════════════════════════════════════════════════════
CHOOSE THE RIGHT OPERATION (critical for complex shapes)
═══════════════════════════════════════════════════════════════

- Rotational symmetry (bottles, knobs, domes, vases) → .revolve()
- Varying cross-section (tapered housing, organic transitions) → .loft()
- Hollow body (enclosures, cases, cups, boxes) → .shell()
- Profile along a path (tubing, rails, channels) → .sweep()
- Repeating radial features (gears, spokes, fan blades) → math + .polarArray()
- Simple prismatic parts (plates, blocks, cylinders) → .box() / .circle().extrude()

DO NOT use .box() + .cut() to approximate curved/organic shapes.
Use the correct operation for the geometry.

Example 1 — Cylinder with bolt pattern:
"80mm dia × 70mm tall cylinder, 3 M6 holes on bottom at 120° on 60mm BCD"
```python
import cadquery as cq
import math
od, height, bolt_d, bcd = 80.0, 70.0, 6.0, 60.0
result = cq.Workplane('XY').circle(od/2).extrude(height)
pts = [(bcd/2*math.cos(math.radians(a)), bcd/2*math.sin(math.radians(a))) for a in [0,120,240]]
result = result.faces('<Z').workplane().pushPoints(pts).hole(bolt_d)
cq.exporters.export(result, '/tmp/cq_output.step')
```

Example 5 — Revolved shape (bottle/vase/dome):
"Water bottle 70mm dia × 200mm tall with tapered neck"
```python
import cadquery as cq
# REVOLVE RULES:
# 1. The 2D profile must be a CLOSED shape
# 2. All profile points must have x >= 0 (do NOT cross the revolution axis)
# 3. Start and end the profile ON the axis (x=0) to create a solid of revolution
# 4. Work on the XZ plane; revolve around the Y axis via (0,0,0)→(0,1,0)
# Profile: half cross-section (x=radius, y=height) from bottom-center to top-center
bottle_radius = 35.0
neck_radius = 15.0
body_height = 140.0
total_height = 200.0
profile_pts = [
    (0, 0),                    # Bottom center (ON axis)
    (bottle_radius, 0),        # Bottom edge
    (bottle_radius, body_height),  # Body wall
    (neck_radius, 170),        # Shoulder taper
    (neck_radius, total_height),   # Neck top
    (0, total_height),         # Top center (ON axis)
]
result = (
    cq.Workplane('XZ')
    .polyline(profile_pts)
    .close()
    .revolve(360, (0, 0, 0), (0, 1, 0))
)
cq.exporters.export(result, '/tmp/cq_output.step')
```

REVOLVE RULES (critical — violating these causes empty geometry or crashes):
- The 2D profile must be a CLOSED shape (polyline + .close())
- All profile x-coordinates must be >= 0 (NEVER cross the revolution axis)
- Start and end the profile ON the axis (x=0) to create a watertight solid
- Use the XZ workplane and revolve around Y: .revolve(360, (0,0,0), (0,1,0))
- Use named variables for dimensions (parametric, editable)

Example 7 — Spur gear with involute tooth profile:
"Spur gear, 20 teeth, module 2, 10mm thick, 8mm bore"
```python
import cadquery as cq
import math
mod = 2.0
z = 20
pa = math.radians(20)  # pressure angle
pitch_r = mod * z / 2
base_r = pitch_r * math.cos(pa)
outer_r = pitch_r + mod
root_r = pitch_r - 1.25 * mod
thick = 10.0
tooth_angle = 2 * math.pi / z

def involute_point(base_r, t):
    x = base_r * (math.cos(t) + t * math.sin(t))
    y = base_r * (math.sin(t) - t * math.cos(t))
    return (x, y)

def involute_intersect_r(base_r, r):
    return math.sqrt((r/base_r)**2 - 1)

pts = []
for i in range(z):
    rot = i * tooth_angle
    # Involute curve points from base to tip (4 points per side)
    t_tip = involute_intersect_r(base_r, outer_r)
    t_pitch = involute_intersect_r(base_r, pitch_r)
    # Tooth thickness at pitch circle
    tooth_thick_angle = math.pi / (2 * z)
    offset = tooth_thick_angle + t_pitch * math.tan(pa) * 0  # simplified
    for t in [0, t_tip * 0.33, t_tip * 0.67, t_tip]:
        ix, iy = involute_point(base_r, t)
        ca, sa = math.cos(rot + tooth_thick_angle), math.sin(rot + tooth_thick_angle)
        pts.append((ix*ca - iy*sa, ix*sa + iy*ca))
    for t in [t_tip, t_tip * 0.67, t_tip * 0.33, 0]:
        ix, iy = involute_point(base_r, t)
        iy = -iy  # mirror
        ca, sa = math.cos(rot - tooth_thick_angle), math.sin(rot - tooth_thick_angle)
        pts.append((ix*ca - iy*sa, ix*sa + iy*ca))
    # Root arc point
    next_rot = (i + 1) * tooth_angle
    pts.append((root_r * math.cos(next_rot), root_r * math.sin(next_rot)))
result = cq.Workplane('XY').polyline(pts).close().extrude(thick)
result = result.faces('>Z').workplane().hole(8)
bore = cq.Workplane('XY').circle(8).extrude(thick)
result = result.cut(bore)
cq.exporters.export(result, '/tmp/cq_output.step')
```

Example 9 — Concentric bores / counterbored holes at specific positions:
"35×20×8mm plate, two sets of concentric holes at [8.5,10] and [26.5,10]: Ø14mm bore, Ø8mm countersunk hole, Ø3.5mm pilot"
```python
import cadquery as cq
import math
plate_length = 35.0
plate_width = 20.0
plate_thickness = 8.0
# Hole positions (from corner coordinates to center-based)
hole_positions = [
    (8.5 - plate_length/2, 10.0 - plate_width/2),
    (26.5 - plate_length/2, 10.0 - plate_width/2),
]
result = cq.Workplane('XY').box(plate_length, plate_width, plate_thickness)
# Apply fillets to top edges
try:
    result = result.edges('>Z').fillet(4.0)
except Exception:
    pass
# Create concentric holes at each position — LARGEST FIRST, then smaller
# 1. Main bore Ø14mm (through)
result = result.faces('>Z').workplane().pushPoints(hole_positions).hole(14.0)
# 2. Countersunk mounting hole Ø8mm with 45° countersink
result = result.faces('>Z').workplane().pushPoints(hole_positions).cskHole(8.0, 14.0, 45.0)
# 3. Pilot hole Ø3.5mm (through)
result = result.faces('>Z').workplane().pushPoints(hole_positions).hole(3.5)
cq.exporters.export(result, '/tmp/cq_output.step')
```

KEY RULES FOR CONCENTRIC HOLES:
- Create holes LARGEST diameter first, then smaller ones at same position
- Use .pushPoints() to position holes at specific coordinates
- Use .cskHole(holeDia, cskDia, cskAngle) for countersunk holes
- Use .cboreHole(holeDia, cboreDia, cboreDepth) for counterbored holes
- Convert corner-based coordinates to CadQuery center-based: x_cq = x_corner - length/2

CONCENTRIC HOLES: When the user specifies MULTIPLE different hole diameters at the SAME XY position (e.g., main bore + mounting hole + pilot hole), create each as a SEPARATE .hole()/.cskHole()/.cboreHole() operation. Do NOT merge them into one operation. Work from LARGEST diameter to SMALLEST.
