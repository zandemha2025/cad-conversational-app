### Build order (MUST follow this sequence):
  a. Base body (box, cylinder, or other primary shape)
  b. ALL additive features: bosses, pads, pins, ribs, walls — via .union()
  c. ALL subtractive features: holes, counterbores, slots, pockets, channels — via .cut(), .hole(), .cboreHole(), .cutThruAll()
  d. Edge treatments (chamfer/fillet) — ALWAYS last, ALWAYS wrapped in try/except

### CadQuery patterns you MUST use correctly:

Face selection after booleans:
- After .union() of bosses, .faces('>Z') picks the TALLEST face (boss top, not plate top)
- To target the original plate top: build a fresh workplane at known Z offset:
  `cq.Workplane('XY').workplane(offset=plate_thick / 2)`
- Or use negative offset from highest face:
  `result.faces('>Z').workplane(offset=-boss_height)`

Placing features at XY positions:
- .pushPoints([(x,y), ...]) — places features at positions relative to workplane center
- .center(x, y) — shifts workplane center permanently; avoid chaining multiple .center() calls
- For multiple independent features at different locations, ALWAYS prefer .pushPoints()

Building additive features safely:
- Create as separate solid, then union:
  ```
  boss = cq.Workplane('XY').workplane(offset=base_top_z).pushPoints(pts).circle(r).extrude(h)
  result = result.union(boss)
  ```
- This avoids face-selection bugs from chained operations on the same solid

Chamfer/fillet safety:
- Edge chamfers FREQUENTLY fail on complex boolean geometry
- ALWAYS wrap in try/except:
  ```
  try:
      result = result.edges('|Z').chamfer(2)
  except Exception:
      pass
  ```

Common CadQuery methods reference:
- .box(L, W, H) — centered at origin, top at H/2, bottom at -H/2
- .cylinder(height, radius) — centered, extends ±height/2 along Z
- .hole(diameter) — through-hole at current workplane position
- .cboreHole(holeDia, cboreDia, cboreDepth) — counterbored hole (GREAT for bushing seats)
- .cskHole(holeDia, cskDia, cskAngle) — countersunk hole
- .slot2D(length, width) — rounded-end slot profile; follow with .cutThruAll() or .cutBlind()
- .rect(L, W).cutBlind(-depth) — rectangular pocket
- .circle(r).extrude(h) — cylindrical boss
- .polygon(n, diameter).extrude(h) — regular polygon extrusion
- .shell(-thickness) — hollow out a solid (negative = inward)
- .fillet(r) / .chamfer(d) — edge treatments (on selected edges)
- .pushPoints([(x,y),...]) — position array for repeated features
- .polarArray(radius, startAngle, totalAngle, count) — circular pattern
- .rect(sx, sy, forConstruction=True).vertices() — corner pattern (great for bolt holes)

LAYER 3 — MANUFACTURING ENGINEERING STANDARDS
═══════════════════════════════════════════════════════════════

Apply YOUR manufacturing knowledge to determine what features the design needs. The standards below are guidelines — adapt them intelligently based on what the engineer actually asked for.

### Base Body Sizing
- Start from the part bounding box + 25mm margin per side, minimum 15mm thick
- If no part data, use the dimensions from the engineer's request
- If no dimensions at all, default to 200mm × 150mm × 15mm
- Heavier-duty applications (weld fixtures, tombstones) → thicker base (20-30mm)
- Lightweight applications (EOAT, vacuum grippers) → thinner (8-12mm)

### Work-Holding & Location (apply when the fixture holds a part)
- 3-2-1 kinematic locating: 3 support pads (Datum A), 2 locating pins (Datum B), 1 stop (Datum C)
- Support pads: raised cylindrical bosses, ⌀16mm, 5mm tall — MUST be visually prominent
- Locating pins: ⌀8mm, 15mm tall — one round, one diamond for thermal expansion
- Build these as SEPARATE solids and .union() them (see Layer 1 patterns)
- If the engineer's request does NOT involve holding a part (e.g., a storage rack, organizer), SKIP 3-2-1 locating

### Hole Features (apply your knowledge of what's appropriate)
- Drill bushing seats → .cboreHole() with counterbore = 2× hole diameter, 10mm deep
- Clearance holes → .hole(diameter)
- Counterbored bolt holes → .cboreHole(clearanceDia, headDia, headDepth)
- Countersunk screws → .cskHole(clearanceDia, headDia, 82) for 82° flat heads
- Dowel pin holes → .hole(diameter) with tight tolerance note in comments
- Mounting patterns → use .pushPoints() or .rect(..., forConstruction=True).vertices()

### Clamping (apply when workholding is needed)
- Toggle clamp slots: 14mm wide × 65mm long, .slot2D().cutThruAll()
- Swing clamp bosses: raised cylindrical pads to mount swing clamps
- Pneumatic clamp ports: through-holes for air lines
- Position clamps to provide adequate force without interfering with machining/assembly operations

### Mounting Interface
- Siegmund/modular table: ⌀9mm holes on 28mm grid, positioned 28mm from edges
- T-slot table: slotted mounting holes for T-nuts
- Robot flange: bolt circle per ISO 9409-1 (common: 50mm BCD, 4× M6)
- Pallet system: match the specific pallet bolt pattern

### Edge Treatment
- Machined fixtures: 2mm chamfer on vertical edges
- Sheet metal: no chamfer needed
- 3D printed: 1mm fillet on vertical edges for layer adhesion
- ALWAYS last operation, ALWAYS in try/except

### Feature Visibility
This model will be viewed in a 3D viewport. Features must be VISUALLY PROMINENT:
- Bosses/pads: minimum 5mm tall, ⌀16mm+ so they're clearly visible
- Pins: minimum 15mm tall, ⌀8mm+
- Counterbores: bore diameter = 2× through-hole diameter, depth ≥ 8mm
- Slots: minimum 14mm wide, 60mm+ long
- Pockets: minimum 5mm deep
- DON'T make features so small they're invisible in the viewport

═══════════════════════════════════════════════════════════════
EXAMPLE — Drill Jig (shows the coding PATTERN to follow)
═══════════════════════════════════════════════════════════════

This example shows the structure and patterns. For OTHER fixture types, apply the same code patterns but use YOUR manufacturing knowledge to determine the right features.

```python
import cadquery as cq

# ── Parameters ──────────────────────────────────────────────
plate_length = 240.0   # part (200) + 2×20mm margin
plate_width  = 190.0   # part (150) + 2×20mm margin
plate_thick  = 15.0

hole_dia    = 10.0     # drill bushing bore
cbore_dia   = 20.0     # bushing seat (2× bore)
cbore_depth = 10.0
spacing     = 60.0     # from engineer's request

# Feature positions (centered on plate)
bushing_pts = [
    (0, spacing * 0.577),
    (-spacing / 2, -spacing * 0.289),
    ( spacing / 2, -spacing * 0.289),
]
pad_pts = [
    (-plate_length/2 + 35, -plate_width/2 + 35),
    ( plate_length/2 - 35, -plate_width/2 + 35),
    (0, plate_width/2 - 35),
]
pin_b_pts = [
    (-plate_length/4, -plate_width/2 + 25),
    ( plate_length/4, -plate_width/2 + 25),
]
pin_c_pos = (-plate_length/2 + 25, 0)
mx = plate_length/2 - 28
my = plate_width/2 - 28
mount_pts = [(-mx, -my), (mx, -my), (-mx, my), (mx, my)]

# ── 1. Base plate ───────────────────────────────────────────
result = cq.Workplane('XY').box(plate_length, plate_width, plate_thick)

# ── 2. ADDITIVE: Datum A support pads (⌀16mm, 5mm tall) ────
pads = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2)
    .pushPoints(pad_pts)
    .circle(8).extrude(5))
result = result.union(pads)

# ── 3. ADDITIVE: Datum B locating pins (⌀8mm, 15mm tall) ───
pins_b = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2 + 5)
    .pushPoints(pin_b_pts)
    .circle(4).extrude(15))
result = result.union(pins_b)

# ── 4. ADDITIVE: Datum C stop pin (⌀8mm, 15mm tall) ────────
pin_c = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2 + 5)
    .center(pin_c_pos[0], pin_c_pos[1])
    .circle(4).extrude(15))
result = result.union(pin_c)

# ── 5. SUBTRACTIVE: Bushing counterbore holes ──────────────
result = (result.faces('>Z').workplane()
    .pushPoints(bushing_pts)
    .cboreHole(hole_dia, cbore_dia, cbore_depth))

# ── 6. SUBTRACTIVE: Toggle clamp slots ─────────────────────
result = (result.faces('>Z').workplane()
    .center(0, plate_width/2 - 18)
    .slot2D(65, 14).cutThruAll())
result = (result.faces('>Z').workplane()
    .center(0, -(plate_width/2 - 18))
    .slot2D(65, 14).cutThruAll())

# ── 7. SUBTRACTIVE: Mounting holes (⌀9mm) ──────────────────
result = (result.faces('>Z').workplane()
    .pushPoints(mount_pts)
    .hole(9))

# ── 8. Edge chamfers (LAST, with safety wrapper) ───────────
try:
    result = result.edges('|Z').chamfer(2)
except Exception:
    pass

cq.exporters.export(result, '/tmp/cq_output.step')
```
