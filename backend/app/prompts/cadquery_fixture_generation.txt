### CadQuery syntax reference:
- .box(L, W, H) — centered at origin, top at H/2, bottom at -H/2
- .cylinder(height, radius) — centered, extends ±height/2 along Z
- .hole(diameter) — through-hole at current workplane position
- .cboreHole(holeDia, cboreDia, cboreDepth) — counterbored hole
- .cskHole(holeDia, cskDia, cskAngle) — countersunk hole
- .slot2D(length, width) — rounded-end slot profile; follow with .cutThruAll() or .cutBlind()
- .rect(L, W).cutBlind(-depth) — rectangular pocket
- .circle(r).extrude(h) — cylindrical boss/pin
- .fillet(r) / .chamfer(d) — edge treatments
- .pushPoints([(x,y),...]) — position array for repeated features
- .polarArray(radius, startAngle, totalAngle, count) — circular pattern
- .rect(sx, sy, forConstruction=True).vertices() — corner pattern for bolt holes

EXAMPLE — Rectangular plate with 4 corner holes
═══════════════════════════════════════════════════════════════

Request: "200mm × 150mm × 15mm plate with four 8mm holes, 20mm from each corner"

```python
import cadquery as cq

length = 200.0
width  = 150.0
thick  = 15.0
hole_d = 8.0
margin = 20.0

result = cq.Workplane('XY').box(length, width, thick)

hole_pts = [
    (-length/2 + margin, -width/2 + margin),
    ( length/2 - margin, -width/2 + margin),
    (-length/2 + margin,  width/2 - margin),
    ( length/2 - margin,  width/2 - margin),
]
result = result.faces('>Z').workplane().pushPoints(hole_pts).hole(hole_d)

cq.exporters.export(result, '/tmp/cq_output.step')
```
