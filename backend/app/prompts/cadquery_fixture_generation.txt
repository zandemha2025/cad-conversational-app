### CadQuery syntax reference:
- .box(L, W, H) — centered at origin, top at H/2, bottom at -H/2

- .slot2D(length, width) — rounded-end slot profile; follow with .cutThruAll() or .cutBlind()
- .rect(L, W).cutBlind(-depth) — rectangular pocket
- .circle(r).extrude(h) — cylindrical boss/pin
- .fillet(r) / .chamfer(d) — edge treatments
- .pushPoints([(x,y),...]) — position array for repeated features
- .polarArray(radius, startAngle, totalAngle, count) — circular pattern
- .rect(sx, sy, forConstruction=True).vertices() — corner pattern for bolt holes

Example 2: Cylinder with attached planar feature (sensor FOV / fin / wing)
Request: "lidar cylinder 80mm dia × 70mm tall with a thin vertical plane representing 90° FOV"

```python
import cadquery as cq
import math

# Main body — cylinder
od = 80.0
height = 70.0
result = cq.Workplane('XY').circle(od / 2).extrude(height)

# FOV surface — thin wedge extending from cylinder center at mid-height
# 90° FOV = ±45° from center axis, represented as a thin triangular fin
fov_angle = 90.0
fov_range = 120.0  # how far the FOV plane extends
fin_thickness = 1.5
half_angle = fov_angle / 2

# Build wedge as a 2D triangle extruded thin
top_y = fov_range * math.tan(math.radians(half_angle))
wedge_pts = [(0, 0), (fov_range, top_y), (fov_range, -top_y)]
fov = (cq.Workplane('XZ')
    .workplane(offset=-fin_thickness / 2)
    .polyline(wedge_pts).close()
    .extrude(fin_thickness))
# Move wedge to mid-height of cylinder
fov = fov.translate((0, 0, height / 2))
result = result.union(fov)

cq.exporters.export(result, '/tmp/cq_output.step')
```

```python
    (-length/2 + margin, -width/2 + margin),
    ( length/2 - margin, -width/2 + margin),
    (-length/2 + margin,  width/2 - margin),
    ( length/2 - margin,  width/2 - margin),

cq.exporters.export(result, '/tmp/cq_output.step')
```
