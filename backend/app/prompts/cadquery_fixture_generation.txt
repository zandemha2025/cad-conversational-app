## CRITICAL CadQuery PATTERNS:

### Selecting the right workplane after modifications:
- After adding bosses/pads, `.faces('>Z')` selects the HIGHEST face (top of boss, not plate)
- To always work on the original plate top face, use absolute workplane:
  `cq.Workplane('XY').workplane(offset=plate_thick)` where plate_thick is the base plate thickness
- For features on the base plate top face, ALWAYS use:
  `result.faces('>Z').workplane(offset=-boss_height)` or explicit offset approach

### Placing features at known XY positions:
- `.pushPoints([(x,y), ...])` places features at absolute positions from workplane center
- `.center(x, y)` shifts the workplane center — affects ALL subsequent operations
- For multiple independent features, prefer `.pushPoints()` over chained `.center()` calls

### Boolean operations for complex shapes:
- Build separate solids and union/cut them:
  `pad = cq.Workplane('XY').workplane(offset=plate_thick).pushPoints(pts).circle(r).extrude(h)`
  `result = result.union(pad)`

### 3-2-1 Locating Principle (REQUIRED for all fixtures)
These are RAISED features on the top face — they MUST be visually prominent:

- Datum A (primary plane, 3 support pads):
  - Three ⌀16mm cylindrical bosses, 5mm tall, on top face of base plate
  - Placed in a triangle pattern: two along the long edge (30mm from edges), one centered on opposite edge
  - Build as a SEPARATE solid and union:
    ```
    pad_pts = [(x1,y1), (x2,y2), (x3,y3)]
    pads = cq.Workplane('XY').workplane(offset=plate_thick).pushPoints(pad_pts).circle(8).extrude(5)
    result = result.union(pads)
    ```

- Datum B (secondary, 2 locating pins):
  - Two pins along the longest edge: ⌀8mm cylindrical pins, 15mm tall
  - One ROUND pin (tight location), one DIAMOND pin (allows thermal expansion)
  - Build on TOP of the datum pads (offset = plate_thick + pad_height):
    ```
    pin_pts = [(x1,y1), (x2,y2)]
    pins = cq.Workplane('XY').workplane(offset=plate_thick + 5).pushPoints(pin_pts).circle(4).extrude(15)
    result = result.union(pins)
    ```

- Datum C (tertiary, 1 stop pin):
  - One ⌀8mm pin, 15mm tall, on perpendicular edge
  - Same construction pattern as Datum B pins

#### assembly_fixture / locating_nest:

### Corner Treatment
- Add 2mm chamfers on all vertical edges of the base plate
- MUST be the LAST operation before export:
  ```
  result = result.edges('|Z').chamfer(2)
  ```
- If chamfer fails (common with complex geometry), wrap in try/except and skip:
  ```
  try:
      result = result.edges('|Z').chamfer(2)
  except:
      pass  # skip chamfer if geometry is too complex
  ```

## COMPLETE EXAMPLE — Drill Jig (follow this pattern closely):

```python
import cadquery as cq

# ── Parameters ──────────────────────────────────────────────
plate_length = 240.0   # mm (200mm part + 2×20mm margin)
plate_width  = 190.0   # mm (150mm part + 2×20mm margin)
plate_thick  = 15.0    # mm

# Drill bushing parameters
hole_dia    = 10.0     # through-hole for drill
cbore_dia   = 20.0     # counterbore seat (2× hole dia)
cbore_depth = 10.0     # counterbore depth
spacing     = 60.0     # hole spacing from request

# Triangular pattern positions (centered on plate)
bushing_pts = [
    (0, spacing * 0.577),                    # top vertex
    (-spacing / 2, -spacing * 0.289),        # bottom-left
    ( spacing / 2, -spacing * 0.289),        # bottom-right
]

# 3-2-1 Datum pad positions
pad_pts = [
    (-plate_length/2 + 35, -plate_width/2 + 35),   # Datum A - pad 1
    ( plate_length/2 - 35, -plate_width/2 + 35),   # Datum A - pad 2
    (0, plate_width/2 - 35),                         # Datum A - pad 3
]

# Locating pin positions
pin_b_pts = [
    (-plate_length/4, -plate_width/2 + 25),   # Datum B - pin 1 (round)
    ( plate_length/4, -plate_width/2 + 25),   # Datum B - pin 2 (diamond)
]
pin_c_pos = (-plate_length/2 + 25, 0)          # Datum C - stop pin

# Mounting hole positions (28mm from edges, Siegmund grid)
mx = plate_length/2 - 28
my = plate_width/2 - 28
mount_pts = [(-mx, -my), (mx, -my), (-mx, my), (mx, my)]

# ── Step 1: Base plate ──────────────────────────────────────
result = cq.Workplane('XY').box(plate_length, plate_width, plate_thick)

# ── Step 2: ADDITIVE — Datum A support pads (⌀16mm, 5mm tall) ──
pads = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2)
    .pushPoints(pad_pts)
    .circle(8).extrude(5))
result = result.union(pads)

# ── Step 3: ADDITIVE — Datum B locating pins (⌀8mm, 15mm tall) ──
pins_b = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2 + 5)
    .pushPoints(pin_b_pts)
    .circle(4).extrude(15))
result = result.union(pins_b)

# ── Step 4: ADDITIVE — Datum C stop pin (⌀8mm, 15mm tall) ──
pin_c = (cq.Workplane('XY')
    .workplane(offset=plate_thick / 2 + 5)
    .center(pin_c_pos[0], pin_c_pos[1])
    .circle(4).extrude(15))
result = result.union(pin_c)

# ── Step 5: SUBTRACTIVE — Drill bushing counterbore holes ──
result = (result.faces('>Z').workplane()
    .pushPoints(bushing_pts)
    .cboreHole(hole_dia, cbore_dia, cbore_depth))

# ── Step 6: SUBTRACTIVE — Toggle clamp slots ──
result = (result.faces('>Z').workplane()
    .center(0, plate_width/2 - 18)
    .slot2D(65, 14).cutThruAll())
result = (result.faces('>Z').workplane()
    .center(0, -(plate_width/2 - 18))
    .slot2D(65, 14).cutThruAll())

# ── Step 7: SUBTRACTIVE — Mounting holes (⌀9mm through) ──
result = (result.faces('>Z').workplane()
    .pushPoints(mount_pts)
    .hole(9))

# ── Step 8: Edge chamfers (LAST) ──
try:
    result = result.edges('|Z').chamfer(2)
except Exception:
    pass  # skip if chamfer fails on complex geometry

cq.exporters.export(result, '/tmp/cq_output.step')
```
